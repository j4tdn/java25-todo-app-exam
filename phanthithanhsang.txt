19. Liệt kê các trạng thái của file trong git, giải thích từng trạng thái
-> Có 4 trạng thái : untracked, unmodified, modified, staged
Untracked + add file => staged
staged + commit => unmodified
unmodified + edit file => modified
modified + stage file => staged
unmodified + remove file => untracked
