2. Viết lệnh thực hiện gộp nhánh bug vào nhánh feature sử dụng git merge
	- git checkout feature
	- git merge bug
3. Viết lệnh thực hiện gộp nhánh feature vào bug sử dụng git rebase
	- git checkout bug
	- git rebase feature
4. Phân biệt git merge và git rebase(giống, khác nhau, khi nào nên sử dụng)
	-giống:
		+ Đều có mụch đích dùng để gộp một nhánh khác vào nhánh hiện tại
	-khác:
	     .merge:
		+ khi push lên trên repo thì merge sẽ sắp xếp các commit theo thứ tự thời gian commit
		+ khi merge thì sẽ tự tạo branch mới
	     .rebase:   	
		+ khi push lên trên repo thì rebase sẽ sắp xếp các commit theo thứ tự push
		+ khi rebase thì không tạo branch mới
5. Phân biệt git fetch và git clone
	-git clone là sẽ lấy toàn bộ dữ liệu trên remote về local
	-git fetch là chỉ lấy những dữ liệu trên remote về những dữ liệu ấy ở local chưa có

8. Git log dùng để làm gì
	- xem lịch sử commit
9. Git status dùng để làm gì
	- xem trạng thái file thư mục đang làm việc
10. Git add dùng để làm gì
	- dùng để đưa các file từ untracked sang trạng thái staged
11. Git commit dùng để làm gì
	- dùng để đưa các file từ trạng thái staged sang trạng thái unmodified
12. Mô tả lệnh để tạo branch ở local

13. Mô tả lệnh để xóa branch ở local
	- git branch -D tenbranch
14. Mô tả lệnh để xóa branch ở remote
	- git push -d remotebranch localbranch
15. Nhánh trung gian là gì, mục đích của nhánh trung gian

          thao tác ở trên nhánh đó thay thế cho nhánh chính ở remote

17. Phân biệt HEAD và BRANCH
	-HEAD: Là một con trỏ có thể di chuyển được có thể trỏ đến các commit
	-Branch: Là nhánh không thể di chuyển được và không thể trỏ đến các commit được
18. Có mấy cách để xóa commit, mô tả và cho ví dụ
	- có 2 cách:
		+ git reset --hard HEAD~n (Xóa commit xóa luôn nội dung)
		+ git reset --soft HEAD~n (Xóa commit giữ nội dung)
19. Liệt kê các trạng thái của file trong git, giải thích từng trạng thái
	-Untracked: là những file chưa được git quản lý
	-Unmodifile: Là những file đã được commit
	-Modifile: Là những file đã qua chỉnh sửa
	-Staged: Là những file đã được add
20. Mô tả các bước cần thực hiện khi nhận 1 task từ dự án, cho ví dụ
	- xác định task thuộc version nào
	- branch nào đại diện cho version này tiếp tục code trên branch đó
	Ví dụ: Mình nhận task có chức năng prime, chức năng prime thuộc branch todo-app-2.0
		phải trỏ head qua todo-app-2.0 để làm chức năng prime
21. Git cherry-pick sử dụng để làm gì
	- lệnh này giúp chúng ta có thể chọn 1 commit cụ thể từ nhánh khác để sử dụng ở nhánh hiện tại
